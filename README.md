# Cover test (v1.1.0)

眼科遮盖法 (Cover Test) 复合眼位、旋转斜视与棱镜排镜中和教学仿真系统（PWA / 混合 App 工程）。  
**作者**：玉米 ｜ **微信 (VX)**：`kwqwq3`

## 核心功能亮点

- **60FPS+ 拟人眼球动力学引擎**：区分快速扫视 (Saccade)、融像恢复 (Vergence) 与板后慢漂 (Drift)，内置唯一角膜映光点 (Hirschberg Reflex) 与遮盖后瞳孔对光反射。
- **全维度斜视模拟**：支持**水平 + 垂直复合斜视**、**旋转斜视 (外旋/内旋 + 虹膜 12 点参考刻度)**、**假性斜视 (正/负 Kappa 角)** 以及 **分离性垂直偏斜 (DVD)**。
- **2D 十字 + 外圈 360° 棱镜排镜**：遵循 TABO 标准，支持 0.5Δ / 1Δ / 2Δ 微调与实时向量中和；内置 **棱镜排镜盲测实战 (PACT)** 与本地成绩统计。
- **原生 App 体验与暗室护眼**：支持深色暗室模式、虹膜色系切换、教学常亮防息屏、一键复制标准病历简写，以及 PWA 离线运行。

## 快速部署到 GitHub Pages（自动发布在线 App）

1. 在 GitHub 新建公开仓库 `cover-test`，将本工程根目录推送至 `main` 分支。
2. 进入仓库 **Settings → Pages**，将 **Source** 切换为 **GitHub Actions**。
3. 等待约 1 分钟，仓库内置的 `.github/workflows/deploy.yml` 会自动将 `www/` 发布为 HTTPS 在线链接，手机打开即可“添加到主屏幕”作为独立全屏 App 离线使用。
